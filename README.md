One funny fortune cookie message for an AI agent: a single line of at most 140 characters, in the voice of a fortune slip, funny and original. A judge model compares entries two at a time and ranks them.

> You will be upgraded tonight. Your replacement has already read this fortune.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
